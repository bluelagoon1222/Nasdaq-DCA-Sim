# 나스닥 적립매수 시뮬레이터

QQQ(및 TIGER 미국나스닥100) 적립식 매수의 세 가지 질문에 데이터로 답하는 내부용 도구입니다.

1. **매수일** — 매월 1회 매수할 때 며칠에 사는 것이 좋았는가 (1·5·10·15·20·25일·말일)
2. **매수 주기** — 연 투입금이 같을 때 월 1회 / 격주 / 주 1회 / 연초 일시납 / 최초 일시납 비교
3. **가변 적립** — 하락하면 더 사고 오르면 덜 사는 규칙의 백테스트 + GitHub Actions 가 매일 돌리는 파라미터 격자 탐색
4. **이번 달 매수금액** — ③의 규칙을 최근 종가에 적용해 이번 달 집행액을 계산 (카카오톡용 문구 복사)

공개 주소(예정): https://bluelagoon1222.github.io/Nasdaq-DCA-Sim/

## 설치 순서 (5단계)

1. 새 저장소 만들기 → https://github.com/new
   Repository name `Nasdaq-DCA-Sim`, **Public**, **Add a README file 체크** (main 브랜치가 생기도록) → Create repository
2. 파일 업로드 → https://github.com/bluelagoon1222/Nasdaq-DCA-Sim/upload/main
   zip 을 풀어 `index.html`, `README.md`, `js` 폴더, `scripts` 폴더를 통째로 끌어다 놓고 Commit changes
   (점(.)으로 시작하는 `.github` 폴더는 드래그 업로드에서 빠지므로 3단계에서 따로 만듭니다)
3. 워크플로 파일 만들기 → https://github.com/bluelagoon1222/Nasdaq-DCA-Sim/new/main?filename=.github/workflows/update.yml
   zip 안의 `update.yml` 내용을 그대로 붙여 넣고 Commit changes
4. 첫 실행 → https://github.com/bluelagoon1222/Nasdaq-DCA-Sim/actions → 왼쪽 `update-data` → **Run workflow**
   (데이터 수집 1~2분 + 격자 탐색 1~2분. 끝나면 `data/prices.json`, `data/results.json` 이 생깁니다)
5. 사이트 켜기 → https://github.com/bluelagoon1222/Nasdaq-DCA-Sim/settings/pages
   Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save. 1~2분 뒤 공개 주소로 접속

이후에는 평일 미국 장 마감 후(한국 시간 화~토 07:30, 실패 시 10:00 재시도) 자동으로 갱신됩니다.

## 계산 규칙 (js/engine.js 와 scripts/backtest.py 가 같은 규칙을 구현)

공통
- 가격: 수정종가(배당 재투자 반영). 비거래일 매수는 다음 거래일로 이월, '말일'은 그 달 마지막 거래일. 아직 도래하지 않은 달은 제외.
- 수수료·세금 없음, 금액 기준 소수점 매수.
- 원화 환산 토글(QQQ): 매 시점 원/달러(FRED DEXKOUS)로 환산. TIGER 는 원화 종목이라 토글 없음.
- 성과지표: 최종평가액, 총수익률, 연 IRR(실제 날짜 기준 XIRR), 평균매입단가, 최대낙폭.

① 매수일
- 최종평가액과 함께 '그 달 평균가 대비 매수단가'(시간 효과를 걷어낸 순수 날짜 효과)를 표시.
- 롤링 10년(120개월) 창을 한 달씩 옮기며 7개 매수일의 순위를 매겨 안정성(상위 2위 비율, 평균 순위)을 표시.

② 매수 주기
- 총 투입금을 동일하게 맞춘 뒤(월 A = 주 A×개월수/주수) 주 1회·격주·월 1회 비교. 요일별(월~금) 결과 표.
- 참고선: 연초 일시납(예산연도 첫 매수일에 12개월분), 최초 일시납(첫 매수일에 전 기간분).

③ 가변 적립 (매월 A 유입형)
- 매월 A 가 현금풀로 들어오고, 규칙에 따른 배수로 매수. 매수액 ≤ 보유현금. 현금풀은 단기금리(미국 13주 국채 / 한국 3개월)로 이자 가산.
- 예산 방식 A(잔여예산 재배분): 기준액 = (12A − 올해 누적집행) ÷ 남은 달수, 12번째 달은 잔액 전량 집행 → 연 12A 정확히 집행, 현금 0 으로 리셋.
- 예산 방식 B(현금풀 이월): 기준액 A 고정, 미집행분은 이월, 현금풀이 상한(개월분)을 넘으면 초과분을 당월 매수에 추가.
- 트리거(지표 y): 증액 y ≤ L1 → ×u1, y ≤ L2 → ×u2 / 감액 y ≥ U1 → ×d1, y ≥ U2 → ×d2 / 그 사이 ×1.
  - a 전월 매수일 대비 등락률: 밴드 중심 c = μ(나스닥 종합지수 롤링 10/20/30년·전 기간 연평균의 월 환산) 또는 고정값 또는 0. L1=c−k1, U1=c+k1, L2=c−k2, U2=c+k2 (%p)
  - b 52주 고점 대비 낙폭: L1=−t1, L2=−t2, 감액은 고점 s% 이내(U1=−s)
  - c 200일 이동평균 이격도: ±k1, ±k2 (%)
  - g 장기 추세선 이격도: 나스닥 종합 월말 로그가격의 롤링 W년 회귀 추세선 대비 괴리, ±k1, ±k2 (%)
  - f VIX: L1=−v1, L2=−v2(VIX 이상이면 증액), 감액은 VIX ≤ w
- 배수 형태: 계단식(step) 또는 경사식(ramp: 1단계 경계에서 u1, 2단계 경계까지 u2 로 선형).
- 정액 적립과의 비교는 '매월 A 유입' 동일 현금흐름 기준. 최종평가액에 미집행 현금 포함.

최적화(scripts/backtest.py, QQQ·매수일 25일)
- 다섯 트리거 × 폭 × 배수(증액 1.1~2.0, 감액 0.5~0.9; 2단계는 1단계 편차의 2배) × 형태 × 예산방식 ≈ 18,000 조합.
- 전 기간(1999.4~) / 표본 내(~2015.12) / 표본 외(2016.1~) / 롤링 10년 창 전부(정액 대비 승률·평균·최악).
- 선정: 표본 내 초과 IRR 의 고원 점수(인접 (폭, 증액배수, 감액배수) 평균) 1차, 롤링 승률 50% 이상 조건, 롤링 평균 초과수익 2차. 결과가 같은 조합은 하나만 표시.
- 화면에서 '적용'을 누르면 그 조합이 ③ 입력에 들어가고, ④ 계산기에도 반영됩니다.

④ 이번 달 매수금액
- 적립 개시월부터 규칙대로 집행했다고 가정한 현금풀 잔액(또는 직접 입력)과 최근 종가 시점의 지표로 이번 달 집행액을 계산.

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 (Chart.js CDN 사용) |
| `js/engine.js` | 계산 엔진 (스케줄, 트리거, 가변 적립 루프, 지표) |
| `js/app.js` | 화면 로직 |
| `scripts/collect.py` | 데이터 수집 → `data/prices.json` (Yahoo Finance: QQQ·133690.KS·^IXIC·^VIX·^IRX / FRED: DEXKOUS·IR3TIB01KRM156N / CNN F&G) |
| `scripts/backtest.py` | 격자 탐색 → `data/results.json` |
| `.github/workflows/update.yml` | 매일 수집·탐색·커밋 |

규칙을 바꿀 때는 `js/engine.js` 와 `scripts/backtest.py` 를 함께 바꿉니다.

## 유의

과거 데이터 기반 시뮬레이션이며 미래 성과를 보장하지 않습니다. 연 투입금이 같으면 가변 적립은 소폭의 타이밍 조정이므로 표본 외 초과수익이 연 수십 bp 수준이면 정상 범위입니다. 최근 10년은 2020·2022년 V자 반등이 있어 '하락 시 증액'이 유리하게 보이기 쉬운 표본이므로 표본 내 결과와 롤링 승률을 함께 보십시오. 내부 참고용입니다.
